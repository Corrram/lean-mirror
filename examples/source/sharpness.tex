If \(x\) is a nonnegative real number, then \(x\le\abs{x}\).
Similarly, if \(x\) is a nonpositive real number, then \(-x\le\abs{x}\).
For every \(a\in[0,1]\), there exists a nonnegative real number \(x\) such that
\(a=x \land x=\abs{x}\).
For every \(a\in[0,1]\), there exists a nonpositive real number \(x\) such that
\(a=-x \land -x=\abs{x}\).
